# v0.2.0 功能与验证记录

更新日期：2026-11-15（Asia/Shanghai）。此版本增加标签、声优、社团筛选和外观设置，并检查真实字幕的配对、下载、解析及当前句选择。它仍是开发预发布版本。

## 标签、声优与社团筛选

在发现页选择“标签”“声优”或“社团”，从音源提供的选项中选择条件；作品详情中已提供的标签、声优和社团也可直接点击，进入相应筛选结果。已选条件可移除或清空。选项弹层中的“检索选项名称”只查找该列表里的名称，不是作品全站关键词搜索。

- **ASMR.one**：每类可选一个条件，标签、声优和社团可组合；条件联合匹配，并保留源站关联的翻译版本。关联译作的发行社团可能与原作品不同，因此结果中并非每个版本都直接带有所选社团标识。
- **ASMR18**：使用站点实际提供的标签、声优或社团归档，每次选择一个条件；选择新条件会替换原条件。分页请求继续访问该归档，不把当前已加载作品的本地过滤当作远端筛选。

音源切换、条件变更和翻页使用独立状态。筛选结果继续执行分级显示设置。ASMR18 归档可能混合 `allages`、`boys` 和 `girls`，分级取自每部作品的原始分类，不把整个归档标记为全年龄。站点选项字典本身没有分级字段，不能宣称其中所有名称都经过全年龄分类。

选项来自真实源站标识或链接。若站点选项暂时不可用，界面会提示，并保留已从作品及详情发现的选项；这部分候选不是完整全站字典。缺少字段时不根据名称猜造筛选标识，也不为 ASMR18 归档卡片补写站点未提供的标签、声优或社团。

### 在线筛选验证

通过真实 Kotlin 适配器显式运行：

```sh
./gradlew :core:run --args=filters
```

| 音源 | 选项数量 | 代表查询结果 |
| --- | --- | --- |
| ASMR.one | 标签 422、声优 5554、社团 5887；声优原始响应 5555 项，剔除无效 `N/A` 项 | 三类单项查询各返回首屏 30 条；三类联合查询返回 2 条 |
| ASMR18 | 标签 422、声优 3371、社团 4252 | 三类单项归档首屏各返回 24 条；标签归档第二页 23 条，与第一页无重复 |

ASMR.one 额外使用 `includeTranslationWorks=false` 请求核对所选实体标识，单项及联合条件均通过；应用正常查询保留 `includeTranslationWorks=true`。社团代表查询中，30 条结果包含 18 条直接社团匹配和 12 条关联译作。这是源站的关联版本展开语义，不应把译作的不同发行社团解释为客户端忽略筛选。

ASMR18 对每类归档抽取首条作品，再请求真实详情核对所选筛选标识；没有依赖客户端伪造字段完成检查。以上数量为本次源站响应快照，不是固定全站总量。验证结果为 `PASS scope=upstream_requests_and_entity_mapping`。

## 系统、浅色与深色外观

外观提供“跟随系统”“浅色”“深色”三种选择，设置保存在本机。正常页面、诊断页面与系统栏使用一致的主题配色；重新打开应用继续采用已选模式。

## 字幕显示

播放带有配套字幕的曲目时，在完整播放器的曲目标题下方、进度条上方显示当前句卡片。重叠的双语字幕按行显示；当前时间没有字幕句时显示 `♪`。加载中、下载或解析失败、空时间轴分别给出状态提示。没有配套字幕的曲目不显示该区域。

时间轴随当前播放位置选择字幕句，seek 后重新取当前位置对应的句子；切换曲目时重新加载所配字幕。显示层只展示当前有效句，不把字幕文件的全部文字一次铺开。

### 真实字幕验证

显式运行：

```sh
./gradlew :core:run --args=subtitles
```

ASMR.one 作品 `1683351` 的一条音轨完成同目录字幕配对、下载、字符解码和 VTT 解析，共得到 62 条字幕。首句起点为 6106 毫秒，中间抽样句起点为 147925 毫秒；按这两个位置取句及句末结束边界检查通过，结果为 `PASS scope=remote_pairing_decoding_and_cue_selection_only`。

这项验证确认真实字幕数据到当前句选择的链路。界面显示、双语换行和状态分支另有离线回归覆盖；尚未在真机上核对本版本的实际声画同步、拖动后的显示及长时间切轨表现。

## 发布与验收边界

`v0.2.0` 由 GitHub Actions 构建 Release 变体 APK，并延用此前开发版本的签名，以保留覆盖安装能力。它仍为预发布，不代表已完成正式发行的签名与设备兼容验收。

此前 `v0.1.2` 已确认可以正常启动；本次新版本尚未完成真机回归。安装、主题切换及重开保持、双源筛选、字幕实际同步、后台/锁屏与耳机控制仍需按设备场景继续验收。构建状态与 APK 校验值以对应 Actions 记录和发布附件为准。
