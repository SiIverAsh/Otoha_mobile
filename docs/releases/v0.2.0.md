# Otoha Mobile v0.2.0（预发布）

- 新增标签、声优、社团筛选，也可从作品详情点击进入。ASMR.one 支持组合条件并保留关联翻译版本；ASMR18 每次使用一个站点分类。
- 新增“跟随系统 / 浅色 / 深色”外观设置，重开应用后保持选择。
- 完善播放器字幕卡片：显示当前句，重叠双语分行，加载和错误状态更清楚。字幕位于曲目标题下方、进度条上方，仅在曲目配有字幕时显示。

已通过双源真实筛选请求及真实 VTT 字幕的配对、下载、解码和时间轴取句验证。尚未完成本版本的真机回归，字幕实际同步、seek 后显示与后台播放仍需设备验证。

此 APK 延用此前开发版本签名，可覆盖安装。仍为预发布版本；APK 与校验文件见本次发布附件。
